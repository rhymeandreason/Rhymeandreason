End of Summer

It's the end of September... After an initial spree of building, I worked on other projects in the last 2 months. This was productive, because then I had to use these apps while needing to work on other things. I filled a project folder with hundreds of images and notes. Occasionally I had to fix bugginess with latency. Opus 5.5 is a huge improvement over version 4.8 that I started this project on, and it glides through the changes effortlessly.

There definitely became a small handful of apps that I repeatedly used, and it's satisfying to experience the consolidation in an organic 'double diamond' design process. The more complex tools like Slides, Diagrams, and Video Editor that I was initially excited about, I never used. Instead, Notes window became a trusty pad always at the side of my screen. I folded File Directory and Git tools into sibling panels, and it feels satisfying as a unified Project hub. I find the tall skinny window size extremely useful, and most desktop apps don't allow such a narrow size.

This week I gave my project hub a little visual refresh. It now has cute sticker icons and pastel hues. I've tried the 'stationery aesthetic' on other projects and it's never quite landed...but it feels at home here.

I feel the project has condensed enough to where I could try and release an App for others to try. But I'm not sure that was ever the point.
